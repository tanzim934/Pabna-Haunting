# Project guidance for coding assistants
- Keep this a standalone, deployable Vite + React SPA.
- The primary hackathon flow is Gateway > Surveillance > Archive > Lockdown.
- Do not introduce paid Base44 auth, APIs, or credentials without separate written requirements.
- Use src/lib/haunting.js for all persisted progress and keep puzzle state deterministic.
- Do not place real passwords, tokens, or API keys in public client files.
- Maintain the English/Bengali toggle and reduced-motion accessibility support.
